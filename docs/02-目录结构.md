# 02 · 目录结构

## 1. 仓库总览

```
Ask Knowledge AI Learning Partner/
├── docs/                     # 本文档集（设计稿）
├── backend/                  # 自建业务后端（FastAPI）
├── frontend/                 # 自建前端（Vue 3 + TS + Vite）
├── dify/                     # Dify 资产：DSL 导出、Prompt 备份、配置说明
├── deploy/                   # 部署脚本与编排
│   ├── docker-compose.app.yml
│   ├── nginx.conf            # SSE 必须 proxy_buffering off
│   └── .env.example
├── data/                     # 运行时数据（不入库）
│   ├── uploads/{tenant}/{kb}/{doc}{ext}

└── scripts/                  # 运维脚本（初始化、迁移、健康检查、spike 验证、schema 自检 check_schema.py）
```

## 6. 命名与代码规范

- 数据库：表名单数小写下划线；时间统一 `TIMESTAMPTZ`；软删统一 `is_deleted + deleted_at`。
- Python：`ruff` 格式化 + 类型标注齐全；Service 层不直接写 SQL，Repository 层收口。
- API：统一前缀 `/api/v1`；返回体 `{ "code": 0, "message": "ok", "data": {...}, "request_id": "..." }`。
- 前端：所有请求经 `api/http.ts`；SSE 仅经 `utils/sse.ts`。
- 文件命名：与 `docs/03` 的表名保持一致，便于对照。
