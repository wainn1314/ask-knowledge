# Ask Knowledge · AI 学习伙伴 —— 技术设计文档

> 版本：v0.1（技术方案评审稿）
> 范围：MVP —— 文档管理 / 知识库管理 / AI 知识问答 / 智能出题 / 错题本 / 对话历史 / 内容审核
> 架构基线：**Dify 1.17.0（RAG + LLM 编排引擎）+ 自建业务后端 + 自建前端**

---

## 1. 方案一句话

**Dify 负责"能解析、能检索、能生成、能流式、能引用"；自建后端负责"业务的事"**（多租户、权限、错题本、出题记录、对话归档、审核日志、上传编排、成本与配额）；**自建前端负责全部界面**——不使用 Dify 自带前端，从而规避其"不得移除 LOGO"条款，也不依赖其"多工作区"能力。

## 4. 关键决策（含理由与风险）

| # | 决策 | 理由 | 风险 / 缓解 |
|---|---|---|---|
| D1 | 用 Dify 做 RAG 引擎，**不用**它的前端 | 省掉解析适配、向量库运维、检索重排、流式引用约 18 人日；只用 API 则不受"不得改 LOGO"约束 | 需自建全部页面（已在工时内） |
| D2 | **一个 Dify workspace**，不做"每租户一 workspace" | Dify LICENSE 第 1.a 条：未经书面授权不得用其源码运营多租户环境（tenant = workspace） | 租户隔离改由后端强制 `tenant_id` + 每租户独立 KB；对外 SaaS 前需评估商业授权 |
| D3 | 分块参数按需求填 **512 / 50**，但单位是**字符** | Dify 源码 `EnhanceRecursiveCharacterTextSplitter` 用 `_character_encoder`（len），文档亦写 characters | 中文近似 1 字符≈1 token（BGE 系）可接受；英文偏小，交付文档注明；需要严格 token 时改走"自建分块 + create-by-text" |
| D4 | MinerU 采用**官方 API 或本地部署服务**，由后端调用 | 插件（langgenius/mineru v0.5.8）是 Tool，能否作为知识管道提取节点需实测；后端直调最可控，且能插入审核卡点 | spike-1 验证；两条路径都保留 |
| D5 | **chunk 权威数据留在 Dify** | 省一套 chunk 表与双写一致性；引用直接用 `retriever_resources` | 出题溯源用 `segment_id`；文档级权限过滤由后端在传入 `dataset_id` 时保证 |
| D6 | 审核"双保险"：Dify moderation 扩展点 + 后端上传前审核 | Dify 覆盖问答输入/输出（流式按 100 字符分段）；**文档导入无 hook**，必须后端补 | 需自建适配服务（约 100 行） |
| D7 | 异步任务用"数据库任务表 + 后台 worker" | MVP 组件最少；解析/嵌入是分钟级任务，必须可重试、可观测 | 量大后再迁 Celery/Redis 队列 |

## 5. 待确认假设（未确认前按此执行）

| # | 假设 | 若否定则影响 |
|---|---|---|
| A1 | 后端 Python 3.11 + FastAPI + SQLAlchemy 2.0 + Alembic | 目录结构与依赖需重写（Dify 生态为 Python，推荐合流） |
| A2 | 前端 Vue 3 + TS + Vite + Element Plus + Pinia | 前端目录与组件库替换 |
| A3 | 数据库 PostgreSQL 16（业务库） | 若用 MySQL，DDL 的 JSONB / 部分索引需改写 |
| A4 | LLM/Embedding 复用 Dify 侧已配置的模型（通义/DeepSeek 等），后端不直连模型 | 若后端需直连，需补模型网关 |
| A5 | MVP 交付形态为"单组织 + 多团队"隔离；对外 SaaS 多租户后置 | 直接决定 Dify 部署形态与许可证谈判 |
| A6 | MinerU 走本地部署（CPU 版可跑）或官方 API，二选一由 `PARSER_MODE` 切换 | 影响解析耗时与成本预算 |

## 6. MVP 功能 ↔ 实现落点（速查）

| 需求 | 落点 |
|---|---|
| 文档管理（5 格式、512/50、入库） | 后端上传编排 + MinerU 服务 + Dify Dataset API（详见 01 §4.1） |
| 知识库管理（CRUD/归属/权限/多租户） | 后端 `kb` / `kb_member` 表 + Dify Dataset API 镜像 |
| AI 问答（Top-K/引用/流式） | Dify Chatflow + `/chat-messages` SSE 透传 |
| 智能出题（4 题型/题量/难度） | Dify Workflow + 后端 `quiz` / `question` 表 |
| 错题本（标记掌握/删除） | 后端 `wrong_book` / `answer_record` |
| 对话历史（回溯/续聊） | 后端归档 + Dify `conversation_id` |
| 内容审核（导入 + 输出） | Dify moderation 扩展点 + 后端上传审核 + `audit_log` |
